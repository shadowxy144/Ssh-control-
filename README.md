🚀 SSH Control & Management Tool
A lightweight, lightning-fast Bash utility to effortlessly control and monitor your OpenSSH server.

⚡ Features
🚀 Instant Control: Start or stop your SSH server with a single keystroke.

📊 Live Logs: Monitor authentication attempts and server status in real-time.

⚙️ Auto-Start Toggle: Easily configure whether SSH starts automatically on system boot.

🛡️ Lightweight & Clean: Pure Bash script, no bloated dependencies.

🛠️ Installation & Usage
Get up and running in seconds:

Bash
# 1. Clone the repository
git clone https://github.com/shadowxy144/Ssh-control-.git

# 2. cd Ssh-control-
cd control 

# 3. Grant execution permissions
chmod +x sshstart.sh

# 4. Run the tool (sudo required for service management)
sudo ./sshstart.sh
